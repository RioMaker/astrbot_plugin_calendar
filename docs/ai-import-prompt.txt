请为“历记”日历生成批量导入文本。

日期范围：【填写起止日期，或明确指定日期列表】
具体要求：【填写需要标记的含义、层数和事件内容；计划请注明“计划”】
当前画笔名称：【默认是“得财”“破财”；如已修改，请从页面模板复制实际名称】

输出规则：
1. 仅输出一个合法 JSON 对象，不要解释、注释或省略号。format 固定为 "liji-import-v1"。
2. entries 为记录数组，每条使用 date 指定有效的公历 YYYY-MM-DD，年份在 1901–2099 之间；也支持 YYYY、YYYY-MM 的年、月记录，三种层级各自独立。
3. marks 为标记数组，每个标记使用 pen（现有画笔名称，必须完全一致）、layers（1–3 的整数，省略为 1）。每条最多四种不同画笔。
4. events 为事件数组，每个事件使用 text（1–4000 字正文）、color（可选，#RRGGBB；省略用日历默认色）。事件会保存为彩色备注。每个年月日合计最多 50 条备注。
5. marks 和 events 可省略其一，但每条至少有一个标记或事件。不要使用其它字段。
6. 只生成所指定日期；每批最多 500 条记录、512 KiB，超出时分批。示例日期和内容都需要替换。
7. 已有内容会保留：标记只补足至 layers；同一日期、正文和颜色相同的事件会跳过。需要区分的同名事件请在正文写明时间或编号。
8. 不要编造已发生事件，不确定内容不要当作事实。

格式示例（默认画笔）：
{
  "format": "liji-import-v1",
  "entries": [
    {
      "date": "2026-11-15",
      "marks": [{"pen": "得财", "layers": 2}],
      "events": [{"text": "计划：核对本月收入", "color": "#658773"}]
    },
    {
      "date": "2026-11-30",
      "events": [{"text": "计划：月末复盘"}]
    }
  ]
}
